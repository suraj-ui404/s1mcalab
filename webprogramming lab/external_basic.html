HTML Stands for Hyper Text Markup Language

HTML, short for HyperText Markup Language, is the standard language used to create and structure the backbone of all web pages. It is not a programming language, but rather a markup language. This means it uses a system of code tags to annotate text, images, and other content to tell a web browser exactly how to structure and display them.
